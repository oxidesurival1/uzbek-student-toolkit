# Talaba Yordamchisi 🎓

O‘zbek tilidagi bepul, ochiq kodli mini web-ilova. Talabalar uchun kundalik hisob-kitoblarni osonlashtiradi.

## Imkoniyatlar
- Baholarning o‘rtacha qiymatini hisoblash
- Sonning foizini topish
- mm, cm, m va km birliklarini aylantirish

## Ishga tushirish

Python 3.10 yoki undan yangiroq versiya kerak.

```bash
git clone https://github.com/oxidesurival1/uzbek-student-toolkit.git
cd uzbek-student-toolkit
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

Linux/macOS:
```bash
source .venv/bin/activate
```

Kutubxonalarni o‘rnatish va ishga tushirish:
```bash
pip install -r requirements.txt
streamlit run app.py
```

pytest
